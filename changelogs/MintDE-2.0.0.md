# MintDE 2.0.0 — macOS-style desktop

MintDE is rebuilt from the ground up as a desktop that looks and behaves much like macOS. All artwork and code are original; the UI font is Inter (SIL Open Font License).

- **Windows:** several apps can be open at once, with stacking order and focus. Windows have rounded corners, soft shadows and macOS-style traffic lights (close, minimize to the Dock, zoom), which show ×, − and + on hover and turn grey when the window is inactive. Windows can be dragged by the title bar or toolbar, double-clicked to zoom, and resized from the right edge, bottom edge or corner with matching pointer shapes. Unified toolbars and full-height sidebars are used where macOS uses them.
- **Menu bar:** translucent, blurred menu bar with a Mint leaf menu (About MintOS, System Settings…, Launchpad, Restart…, Shut Down…), the bold name of the active app, and File, Edit, View, Window and Help menus. Menus show keyboard shortcuts, greyed-out unavailable items, separators and accent-coloured hover highlights. The right side has Control Center, Spotlight and a real date and time (for example "Mon 9 Nov 15:04") from the computer's clock.
- **Dock:** frosted-glass Dock with app icons, name tooltips on hover, a dot under running apps, a separator and a Trash.
- **Launchpad:** a full-screen grid of every app over the blurred, dimmed desktop.
- **Spotlight (⌘Space):** search apps and Settings panes, use the arrow keys to select and Enter to open.
- **Control Center:** a Dark Mode toggle, accent colours, input status and display information.
- **App switcher (⌘Tab).** Other shortcuts: ⌘Q/⌘W close, ⌘M/⌘H minimize, ⌘, opens Settings, ⌘N opens Files, ⌘L opens Launchpad. The Windows key acts as Command.
- **Appearance:** Light, Dark and Auto (switches by the clock, dark from 19:00 to 07:00). Five accent colours (Mint, Blue, Purple, Orange, Pink). New original "Mint Waves" wallpapers in light and dark versions.
- **Apps redesigned:**
  - Files, Finder-style: Locations sidebar, back button, search filter, Name/Size/Kind list, Quick Look-style preview and a status bar.
  - Settings, System Settings-style: General, Appearance, Wallpaper, Displays, Input, Storage, Network, Privacy and Power.
  - Terminal (fixed-width cells, command recall with ↑) and Notes (title line, word wrap, autosave to Session RAM).
  - System Monitor, Storage & Logs (Console-style), Hardware & Drivers (System Information-style), Network, and Disk Utility (Erase sheet, offered only for blank disks).
  - About This Mac-style About windows, and a new Calculator.
- **New icons** for every app, plus original pointer shapes (arrow, I-beam, resize arrows).
